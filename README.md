# CW Battle Royale — 팬 페이지 (시안 v0.1)

레이더 · 섬 지도 · 학생 명부를 한 화면에 모은 전술 HUD 스타일의 비공식 팬 페이지입니다.

## 화면 구성
| 영역 | 내용 |
|---|---|
| 정기 방송 / 규칙·공지 | 상단 텍스트 패널 |
| 레이더 | 선택한 학생 주변(반경 4칸) 생존자 표시 |
| 출석부 | 칸 그리드, 사망자는 X 표시, 상태 필터와 검색 |
| 섬 지도 | A–J / 1–10 격자, 금지구역·예정구역·학생 위치 |
| 능력치 | 선택한 학생의 6각형 스탯 차트 |
| 학생 기록 | 상세 프로필 |

## 데이터 수정
모든 내용은 `data.js` 한 파일에 있습니다. 학생·방송·금지구역을 바꾸면 화면에 바로 반영됩니다.

## 로컬 실행
빌드 도구 없이 정적 파일만으로 동작합니다.
```
python -m http.server 5173
```
→ http://localhost:5173

디자인: 앰버 단색 형광체 단말기 + 감독관 책상 장면. 글꼴은 나눔고딕코딩(화면)과 나눔펜(종이). 이유는 [DESIGN.md](DESIGN.md) 참고.
